# C Programming: Personal Projects and Academic Coursework

## Overview

This repository serves as a formal collection of software implementations, academic assignments, and personal exploratory projects developed in the **C programming language**. It reflects my ongoing study of low-level computer science fundamentals, efficient memory management, algorithm design, and system-level operations acquired through university coursework and independent engineering practice.

The primary objective of this repository is to document my technical progress and demonstrate clean, standard-compliant, and modular C coding practices.

---

## Technical Focus Areas

The projects and exercises contained in this repository cover a range of foundational topics in software engineering and computer systems:

* **Memory Management & Architecture:** Dynamic memory allocation using `malloc`, `calloc`, `realloc`, and manual deallocation with `free`. Emphasis is placed on avoiding memory leaks, preventing dangling pointers, and writing safe code using strict diagnostic tools.
* **Data Structures & Algorithm Implementation:** Custom low-level builds of essential data structures, including singly and doubly linked lists, binary search trees, hash maps, queues, and stacks, along with fundamental sorting and searching algorithms.
* **System Programming & POSIX Systems:** Interface design with operating system primitives, low-level file I/O operations, signal handling, process execution, and multi-threading models.
* **Modular Software Design:** Organizing code into cohesive header (`.h`) and implementation (`.c`) files, enforcing abstraction boundaries, and writing maintainable code architecture.
